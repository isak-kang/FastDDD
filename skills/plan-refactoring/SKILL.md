# 리팩토링 계획 (Plan Refactoring)

## 목적

코드 수정 전에 안전한 리팩토링 계획을 수립한다.

## 필요한 입력

- 대상 모듈, 파일, 또는 동작
- 현재 코드 컨텍스트
- AGENTS.md
- 알려진 문제점

## 진행 순서

1. 현재 구조를 설명한다.
2. 구체적인 문제를 파악한다.
3. 리팩토링 목표와 비목표를 정의한다.
4. 변경되어서는 안 되는 동작을 정의한다.
5. 목표 구조를 제안한다.
6. 마이그레이션 전략을 정의한다.
7. 리스크와 롤백 계획을 정의한다.
8. 특성화 테스트와 회귀 테스트를 정의한다.
9. 이 스킬에서는 코드를 구현하지 않는다.

## 출력

다음 경로에 생성 또는 업데이트:

```text
docs/refactoring/{target-name}.refactoring.md
```
