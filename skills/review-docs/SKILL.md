# 문서 리뷰 (Review Docs)

## 목적

기술 문서의 정확성과 일관성을 검토한다.

## 체크리스트

- 문서가 실제 구현과 일치하는가?
- 엔드포인트 경로, 메서드, 파라미터, 응답이 정확한가?
- 에러 코드가 코드와 일치하는가?
- 예시 JSON이 유효한가?
- Open Questions가 아직 미해결 상태인가?
- 완료 기준(Done Criteria)이 측정 가능한가?
- 배포가 필요한 경우 Notion/Drive 메타데이터 필드가 있는가?

## 출력

- 누락된 섹션
- 부정확한 섹션
- 수정 제안
- 배포 준비 상태
