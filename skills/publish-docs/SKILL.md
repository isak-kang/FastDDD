# 문서 배포 (Publish Docs)

## 목적

검토된 문서를 외부 배포를 위해 준비한다.

## 필요한 입력

- 검토된 문서 파일
- 배포 대상
- Notion 데이터베이스 또는 페이지 매핑 (사용하는 경우)
- Google Drive 폴더 매핑 (사용하는 경우)

## 진행 순서

1. 문서가 검토되었는지 확인한다.
2. doc_id, type, domain, status, version 등 메타데이터를 확인한다.
3. 배포 계획을 준비한다.
4. 상태 변경 작업이 포함된 경우 확인 후에만 MCP 또는 외부 도구를 사용한다.
5. 배포 결과를 배포 로그에 기록한다.

## 가드레일

- 스킬 파일에 토큰이나 시크릿을 저장하지 않는다.
- 명시적으로 요청받지 않는 한 외부 문서를 삭제하지 않는다.
- 중복 생성 대신 doc_id로 업데이트하는 것을 선호한다.
- Git Markdown이 소스 오브 트루스로 유지되어야 한다.

## 출력

- 배포 계획
- 대상 매핑
- 배포 로그 항목
