# 코드 리뷰 (Review Code)

## 목적

머지 또는 계속 진행 전에 코드 변경 사항을 리뷰한다.

## 리뷰 체크리스트

### 요구사항

- 구현이 PRD 또는 리팩토링 계획과 일치하는가?
- 범위 밖의 동작이 추가되었는가?

### 아키텍처

- 코드가 AGENTS.md를 따르는가?
- 레이어 경계가 유지되는가?
- 비즈니스 로직이 router/controller에서 분리되어 있는가?

### 신뢰성

- 에러가 명시적으로 처리되는가?
- 여러 시스템이 관여된 경우 부분 실패가 처리되는가?
- 생성/업로드/실행 작업에서 멱등성이 고려되는가?

### 데이터

- DTO와 영속성 모델이 명확히 분리되는가?
- DB 쿼리가 안전하고 이해하기 쉬운가?
- 마이그레이션 영향이 고려되는가?

### 비동기 및 성능

- 비동기 흐름 내에서 블로킹 호출이 피해지는가?
- 장시간 실행 태스크가 필요한 경우 요청/응답 경로 밖으로 이동되는가?

### 테스트

- 비즈니스 규칙이 테스트되는가?
- 실패 경로가 테스트되는가?
- API 컨트랙트가 검증되는가?

### 유지보수성

- 이름이 명확한가?
- 함수가 충분히 작은가?
- 중복이 정당화되는가?
- 추상화가 필요한가?

## 출력

- 심각한 문제
- 수정 제안
- 테스트 누락
- 리스크 요약
