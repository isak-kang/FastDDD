# 리팩토링 구현 (Implement Refactoring)

## 목적

외부 동작을 유지하면서 리팩토링 계획을 실행한다.

## 필요한 입력

- 리팩토링 계획
- AGENTS.md
- 기존 테스트
- 현재 코드베이스

## 진행 순서

1. 리팩토링 계획을 읽는다.
2. AGENTS.md를 읽는다.
3. 변경되어서는 안 되는 공개 인터페이스를 파악한다.
4. 현재 동작에 대한 특성화 테스트를 추가하거나 확인한다.
5. 작고 되돌릴 수 있는 변경을 한다.
6. 각 주요 단계 이후 회귀 검증을 실행하거나 설명한다.
7. 계획에서 명시적으로 허용하지 않는 한 외부 동작을 변경하지 않는다.
8. 변경 전/후 구조와 잔여 리스크를 요약한다.

## 가드레일

- API 응답 스키마를 변경하지 않는다.
- 에러 형식을 변경하지 않는다.
- 계획되지 않은 한 DB 문서 구조를 변경하지 않는다.
- 불필요한 추상화를 도입하지 않는다.
- 커밋은 작고 리뷰 가능하게 유지한다.
