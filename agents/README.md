# agents/

This directory is reserved for agent-related notes and shared tooling in the FastDDD repo.

**Agent instructions live in each template**, not here. For example, the DDD backend template ships its own [AGENTS.md](../templates/ddd/AGENTS.md) at the template root. Copy or bootstrap a template into your project and use that file (and the template's .cursor/ rules and skills) as the source of truth for AI assistants.

The former AGENTS.template.md and CLAUDE.template.md files were removed in favor of per-template AGENTS.md files.
